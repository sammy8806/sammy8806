## Featured projects

### [foghorn](https://github.com/sammy8806/foghorn)
Cross-platform desktop alert monitor for Alertmanager, Grafana Alerting, Prometheus, and Better Stack. View and manage silences, see who's on-call at a glance, and get native desktop notifications.
*Go · Wails · Svelte*

### [service-starter](https://github.com/sammy8806/service-starter)
System-tray app that auto-discovers local projects, monitors port usage and conflicts, and tracks dependency health (Docker, external services, APIs).
*Electron · React · TypeScript*

### [x32-patch-list](https://github.com/sammy8806/x32-patch-list)
Browser/PWA tool that generates printable patch lists from Behringer X32 scene files — fully client-side, nothing ever uploaded. Works offline once loaded.
*TypeScript · Bun · PWA*

### [bandai](https://github.com/sammy8806/bandai)
Full-stack band-management platform: members, songs, rehearsals, setlists, and show planning in one place.
*Spring Boot · React · PostgreSQL*
